                                   Abstract

Reinforcement learning agents for continuous control must select precise, co-
ordinated actions while responding to complex environment dynamics. Deep
Q-Networks (DQN) operate on discrete actions, so applying them to multidimen-
sional continuous control requires joint-action discretisation that grows rapidly
with the number of action dimensions. This study investigates whether a diffusion
policy can imitate continuous expert behaviour in LunarLanderContinuous-v3 more
effectively than standard behaviour cloning and a discretised DQN baseline. The
comparison evaluates episodic return, successful-landing rate, action smoothness,
and inference cost under repeated evaluation seeds.

1 Introduction

Reinforcement Learning (RL) is a paradigm of machine learning that focuses on training agents to
make decisions by interacting with an environment. In continuous control problems, agents learn
policies that produce actions within an environment that attempt to maximize overall reward over
time (Milvus, n.d.; Terven, 2025), which can be written as follows:

One approach to continuous control is to adapt the Deep Q-Network (DQN), which combines
Q-learning with a neural network that estimates the value of each available action. DQN requires
a finite action set, however, so each continuous action dimension must be divided into bins. For
LunarLanderContinuous-v3, independently discretising both control dimensions into  bins creates
2 joint actions, trading control precision for a rapidly expanding output space. Standard deterministic
policies also produce one preferred action for each state and may average across distinct valid
behaviours represented in demonstration data.

To address these limitations, this paper explores the use of diffusion models in reinforcement learning
for continuous control tasks. This leads to the following research question:

To what extent can a diffusion policy improve imitation learning for complex continuous
control in LunarLanderContinuous-v3, compared with standard behaviour cloning and
a discretised DQN baseline?

2 Background: Denoising Diffusion Models

Diffusion models are a class of generative models that can learn to produce complex distributions
of data, which can be used to represent the full range of valid, diverse actions in continuous action
spaces rather than collapsing them into a single averaged answer (Chi et al., 2023).

                1
A Diffusion Model has two main components: a forward process and a reverse process. The forward
process progressively adds gaussian noise to a sample of data until the sample becomes completely
random noise. The reverse process is a neural network that learns to predict and remove the noise
added at each step with a concrete training objective: predict the noise added at a random step. Instead
of learning to generate a sample from scratch, the network learns to denoise a noisy sample. By
replicating this process, the trained network can generate new samples from pure noise.

2.3 From images to actions

Applying diffusion concepts to reinforcement learning requires changing both what is "diffused"
and how it is generated. Firstly, the data sample 0 is no longer a grid of pixel values, but a vector
representing a continuous action, or a short sequence of future actions (Chi et al., 2023). Secondly,
the network needs to know what state it is acting in, so the current state  is fed into the network
at every denoising step, alongside the noisy action. This turns the network into a policy  ( | ):
starting from random noise, it is repeatedly denoised, using the state as context each time, until a
usable action remains. Chi et al. (2023) predict a short sequence of future actions at once for smoother
behaviour. This paper adopts short action chunks because landing requires coordinated control over
multiple timesteps.

3 Related works

3.1 Discretised and continuous-action value-based control

Mnih et al. (2015) combined Q-learning with a neural network for discrete control. Applying DQN to
LunarLanderContinuous-v3 therefore requires both action dimensions to be discretised;  bins per
dimension produce 2 joint actions. Double DQN improves value estimates by separating action
selection from evaluation (van Hasselt et al., 2015), but leaves this action-space bottleneck unchanged.
DDPG avoids discretisation by learning a deterministic continuous policy (Lillicrap et al., 2015).
Both DDPG and discretised DQN still select one action for each state, whereas a diffusion policy can
model a distribution over valid controls.

3.2 Behaviour cloning and continuous-control demonstrations

Behaviour cloning (BC) learns a policy from expert state-action pairs through supervised learning. It
is the direct baseline for the diffusion student because both models use the same SAC demonstrations
and predict the same action chunks. A deterministic BC model produces one chunk per state and may
average across different valid behaviours. Small errors can also move the policy into states missing
from the training data, where later errors can compound (Ross et al., 2011; Pearce et al., 2023).

Soft Actor-Critic (SAC) is an off-policy, maximum-entropy actor-critic algorithm for continuous
actions (Haarnoja et al., 2018). Its stochastic policy can collect varied successful trajectories. In this
study, SAC supplies the demonstrations; it is the teacher, not an imitation-learning baseline.

3.3 Diffusion models for action generation

Janner et al. (2022) treated planning as denoising full state-action trajectories, showing that diffusion
can represent multimodal, long-horizon behaviour. Full-trajectory denoising is costly for online
control, where actions must respond to a changing state. Pearce et al. (2023) applied diffusion
directly to behaviour cloning, while Chi et al. (2023) combined DDPM-style denoising (Ho et al.,
2020) with state conditioning and receding-horizon action chunks. This study adapts that design to
LunarLanderContinuous-v3. The BC student isolates the effect of diffusion-based action generation,
while the discretised DQN provides the value-based baseline.
